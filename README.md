# Group Agent Flow

面向 QQ 群聊的自主 Agent 插件。它在群内以「固定快照」方式感知新消息，自主决策何时以及如何发言，所有对外动作都通过安全的工具调用完成，而不是让模型直接生成消息。

## 功能特性

- **自主群聊智能体**：基于当前快照判断是否需要回应，合理时自动发言，并可主动保持沉默。
- **只通过工具对外**：发消息、回复、表情回应、戳一戳等一律经工具调用，普通模型输出不会直接进入群聊。
- **增量上下文**：把当前批次的新消息渲染成一段精简上下文注入模型，长上下文更省 token。
- **快照与检索解耦**：近期消息紧凑展示，历史消息按需通过 `search_chat_history` 工具检索，兼顾成本与完整性。
- **多媒体能力**：支持图片、语音转写（STT）等，根据模型能力按需启用。

## 安装

本插件依赖 AstrBot `>= 4.27.4`，支持 aiocqhttp / NapCat 平台。

将本仓库放入 AstrBot 的插件目录后重载插件即可。

## 配置与启用

在插件配置页启用 Agent，并将需要运行的群号加入授权列表。

授权列表默认为空，因此插件初次加载不会在任何群内自主运行；使用 `*` 可授权全部群。

## 配置项说明

插件配置分为以下几个分组，均可在 AstrBot 插件配置页调整：

### Agent settings（智能体）

- `enabled`：是否启用群聊自主观察。
- `authorized_group_ids`：允许运行 Agent 的 QQ 群号列表；为空则不自动运行，`*` 表示所有群。

### Scheduling（调度）

- `debounce_seconds`：普通消息的静默延迟（默认 10 秒）。
- `direct_delay_seconds`：机器人被 @ 时的静默延迟（默认 1 秒）。
- `direct_min_cycle_interval_seconds`：被 @ 触发的推理周期最短间隔（默认 20 秒）。
- `min_cycle_interval_seconds`：推理周期之间的最短间隔（默认 10 秒）。

### Context（上下文与渲染）

- `max_context_tokens`：单轮观察上下文的 token 上限（默认 8192）。超出时优先裁剪最新观察块，较早记录仍可通过工具检索。
- `max_log_records`：每个群最多保留的待处理/进行中 Buffer 记录数（默认 10000）。设为 `0` 可禁用上限。
- `max_text_chars`：单条消息存储的最大摘要长度（默认 4000）。
- `record_self_messages`：是否记录机器人账号自己发的消息（默认关闭）。开启后，机器人回声事件可能进入后续快照并触发新一轮推理。
- `astrbot_tool_blocklist`：在自主循环中**保留** AstrBot 注入的工具（联网搜索、知识库、只读文件等），仅剔除与快照/发送边界冲突的工具。默认剔除 `send_message_to_user`、`get_group_message_history`；可追加其他 AstrBot 工具名以拦截更多。
- `renderer`：上下文渲染格式，可选 `xml_delta`（默认）或 `line_messages`。切换只影响后续新快照的渲染，已有会话历史保持原样。

### Prompt（提示词）

- `custom_system_prompt`：附加的人设或群内行为说明（默认空）。

### Debug（诊断）

- `debug_log`：记录快照准备详情（默认关闭）。

## 上下文渲染格式

插件把每轮快照渲染为一段上下文注入模型，可在配置页 `context.renderer` 选择：

- **XML 增量块**（默认）：单个 `<group_messages_delta>` 结构化块，外层携带群元数据，内部按 XML 组件表达事件。
- **行式消息**：每条消息一行的紧凑格式 `[YYYY/MM/DD HH:MM] (QQ号)昵称: 正文 #消息编号`；同分钟省略时间段、同人连发省略昵称段（省略即继承上一条），长上下文更省 token。

## AstrBot 推荐配置

为避免同一群由两套机制重复维护上下文或触发回复，建议在授权群中：

- 关闭 AstrBot 的群聊上下文感知功能，包括 `群聊消息记录注入上下文`、`持久化群聊消息记录` 和 `主动回复` 开关。插件会自行维护待处理消息，并将当前新的消息加入会话。

如需让 Agent 理解图片：

- 对话模型声明 `image` 模态时，插件可按需读取原图；
- 模型不支持输入图片时，在 AstrBot 中配置 `默认图片转述模型`，由视觉 Provider 提供图片转述。

## 群内管理指令

- `/gaf_status`：查看当前群的授权状态、SQLite Buffer 数量与活动批次。
- `/gaf_clear`：管理员清空当前群的 Buffer、Core 会话和内存调度状态。
