# Group Agent Flow

面向 QQ 群聊的自主 Agent 插件，基于固定快照处理群消息，并仅通过显式动作工具向群内产生可见效果。

## 安装

将本仓库放入 AstrBot 的插件目录后重载插件。

本插件依赖 AstrBot `>= 4.9.2`，目前支持 aiocqhttp / NapCat 平台。

## 配置与启用

在插件配置页启用 Agent，并将需要运行的群号加入授权列表.

授权列表默认为空，因此插件初次加载不会在任何群内自主运行。使用 `*` 可授权全部群。

## 上下文渲染格式

插件把每轮快照渲染为一段上下文注入模型，可在配置页 `context.renderer` 选择：

- `XML 增量块`（默认）：单个 `<group_messages_delta>` 结构化块，外层携带群元数据，内部按 XML 组件表达事件。
- `行式消息`：每条消息一行的紧凑格式 `[YYYY/MM/DD HH:MM] (QQ号)昵称: 正文 #消息编号`；同分钟省略时间段、同人连发省略昵称段（省略即继承上一条），长上下文更省 token。

切换格式只影响后续新快照的渲染；已有会话历史保持原样。

## AstrBot 推荐配置

为避免同一群由两套机制重复维护上下文或触发回复，建议在授权群中：

- 关闭 AstrBot 的群聊上下文感知功能，包括 `群聊消息记录注入上下文`、`持久化群聊消息记录` 和 `主动回复` 开关。插件会自行维护待处理消息，并将当前新的消息加入会话。

如需让 Agent 理解图片：

- 对话模型声明 `image` 模态时，插件可按需读取原图；
- 模型不支持输入图片时，在 AstrBot 中配置 `默认图片转述模型`，由视觉 Provider 提供图片转述。

## 群内管理指令

- `/gaf_status`：查看当前群的授权状态、SQLite Buffer 数量与活动批次。
- `/gaf_clear`：管理员清空当前群的 Buffer、Core 会话和内存调度状态。
